Sum up 19 November's world news in one image: a program that draws the news of Thursday 19 November 2026 as a one-page newspaper front page — 40 stories across 7 regions, every one dated 19 November 2026. Lead: the Trump–Xi–Putin summit in Shenzhen. Numbered briefs below it cover Asia-Pacific, the Middle East, Europe, the Americas, Africa, Science & Space, and Markets, Tech & Sport: the ICJ ruling on the Rohingya case, the Crimea Bridge strike, Iran's Gulf attacks, the COP31 deadlock in Antalya, unrest in Bangladesh, Jeffries set to be Speaker, the Anthropic IPO, Voyager 1, a Van Gogh record sale and an EU loan to Ukraine. Pure Python 3 standard library: an embedded 5x7 bitmap font and flat vector shapes, no network, no randomness — two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
